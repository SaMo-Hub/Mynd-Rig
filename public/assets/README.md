# Assets du personnage

Dépose ici les visuels 2D découpés (PNG à fond transparent) :

- `body.png` — corps / torse
- `head.png` — tête
- `arm-left.png`, `arm-right.png` — bras
- `leg-left.png`, `leg-right.png` — jambes
- `eyes/` — variantes des yeux (ouverts, fermés, mi-clos…)
- `mouths/` — variantes de bouche (expressions)

Chaque pièce est un fichier séparé, pivot idéalement centré sur l'articulation.
